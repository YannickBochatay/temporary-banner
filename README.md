# temporary-banner
Web component for displaying a banner for a specified period

## Demo 

http://yannickbochatay.github.io/temporary-banner

## Example

```html
<temporary-banner start="2026-10-07T08:00Z" end="2026-10-07T18:00Z">
  ⚠️ Maintenance in progress: the app may experience disruption
</temporary-banner>
```
